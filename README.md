# Auto Spa Services Website

This project is a clean, modern single-page landing website for a drop-off-only premium auto detailing and protection business.

## Highlights
- Premium hero section and branding
- Window tint and paint protection film service packages
- Deposit requirement messaging ($50)
- PPF coverage diagram with example coverage areas
- Contact/booking form for customer inquiries
- Mobile-friendly responsive design

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

Example:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000

## Notes
This version is intentionally designed as a conversion-focused marketing site for Auto Spa Services, centered around the business model of a drop-off-only service.
